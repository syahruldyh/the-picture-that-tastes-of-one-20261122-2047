# The picture that tastes of one ingredient

Built for the [make.fun bounty](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047).

One ripe strawberry, drawn procedurally and filling the frame: a deep red body with a sunlit upper-left side, pale seeds tucked into the flesh, a fresh green calyx with a little stem on top, and juice droplets catching the light — all on a warm cream background with a soft shadow underneath. Run `python3 main.py` and it writes `/output/entry.png` (900x900). Python 3 standard library only, no network, deterministic output.
